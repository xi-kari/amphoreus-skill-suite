# 圆桌与陪聊使用指南

## 场景选择

| 对照项 | 陪聊场 | 圆桌场 | 工作场 |
|---|---|---|---|
| 进入信号 | 闲聊、剧情漫谈、角色互动 | 召集多人认真讨论同一命题，或点名“圆桌” | 给出具体对象、动作请求与期待产出 |
| 单一命题 | 可有可无 | 必须有 | 可有多个工作问题，但承办对象与动作需明确 |
| 交付物 | 无 | 无 | 有 |
| 人数与发言 | 单角或沙龙；沙龙同场活跃至多四人，单轮至多八条 | 可全员或指名；每题每人至多两段 | 单卡承办、至多三人会诊，或用户选择的流水线 |
| 互动义务 | 沙龙按兴趣自然交错 | 除首位外，每人至少回应一位前位发言者 | 依职责串行、会诊或移交，不以角色闲谈代替工作 |
| 回执 | 免逐轮回执，收场落一次场级回执 | 免逐轮回执，场末台账一次性收束 | 逐轮三字段回执完整保留 |
| 引证位置 | 台词可用短式出处；全格式落场末台账 | 台词可用短式出处；全格式落场末台账 | 直引随行给全格式出处 |
| 承办 | 不承办 | 不承办 | 由本职角色承办并使用本卡工作模板 |
| 升档 | 对象、动作、产出三要素齐时升档 | 对象、动作、产出三要素齐时出列承办 | 已在工作档；权限门、移交门与停止条件持续有效 |
| 退出 | 用户收场或升档 | 用户收场或升档 | 交付完成，或停止报告写明未完成物与恢复点 |

## 可直接使用的话术

### 圆桌邀请

> 圆桌模式：大家用自己的声音认真聊聊《◯◯◯》。不用跑完整 skill 流程，引证和读取收进场末一个台账就行；长短文体不必整齐，可以反驳、可以开玩笑、可以只答一句。

### 互动要求

> 除第一位外，每个人至少回应一位前面发言的人——同意、反驳、借话头都行；有分歧就留着分歧。

### 正式升档

> ◯◯，这件事正式承办：〈对象＋动作＋要的产出〉。

## 圆桌运行要点

1. 主持只负责点名、秩序、升档信号与回应对提示，不替角色发言，也不把提示写成强制指派。
2. 角色逐条冠名；同场禁区对子不直接对话，需要回应时由第三人搭桥。
3. 有立场空间的命题不强行收敛；主持不得把多数意见写成全场公理，收束时保留分歧。
4. 长短不齐、玩笑、反问、比喻、极短句、拒答和沉默均可成立；连续同构的开场、枚举和判词应被打散。
5. 正文只放角色发言与场面叙述。读取清单、引证全格式、档位变更、升降档记录和缺席标准行统一收入场末一个台账折叠块。
6. 纯知识库直引或降级事实不触发逐轮回执；工作动作一旦出现，立即恢复工作场的回执、授权、边界、停止和移交纪律。
