GET STARTED

安装指北

# 1. 克隆仓库
git clone https://github.com/xi-kari/amphoreus-skill-suite.git

# 2. 拷入技能根(Windows: C:\Users\<你>\.claude\skills\)
cp -r amphoreus-skill-suite/skills/* ~/.claude/skills/

# 3. 校验部署(应输出 PASS,cards=13/13)
python ~/.claude/skills/amphoreus/scripts/validate.py --root ~/.claude/skills --wave all

随后在 Claude Code / Cursor 里直接点名(「用 amphoreus-mydei 帮我追这个死锁」),或呼叫 amphoreus 总路由由它分发。
